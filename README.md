# Weather Prediciton Kaggle Challenge Submission

This repository contains the code and resources used for participating in the [Weather Prediction 2025 Kaggle competition](https://kaggle.com/competitions/weather-prediction-2025) [1]. The goal of the competition is to predict the minimum temperature of the next day given weather data from the past 2 weeks.
